# Materiais Pedagógicos da UCE — Integração com Empresa Júnior

## Sobre este repositório
Este repositório reuniu os materiais didáticos utilizados em uma
Unidade Curricular de Extensão (UCE) integrada a uma Empresa Júnior
no curso de Ciência da Computação de uma universidade pública brasileira.
Os materiais foram organizados em semestres e incluíram planejamentos, cronogramas,
instrumentos de avaliação e orientações para replicação da experiência.

Os documentos foram elaborados para apoiar a oferta da disciplina em dois
períodos consecutivos e facilitaram a adaptação para outros contextos institucionais.

## Estrutura do repositório
- [2025_1_planejamento.md](2025_1_planejamento.md) — Semestre de nivelamento técnico e imersão na Empresa Júnior (fundamentos web, PHP, XAMPP, Git e projeto integrador).
- [2025_2_planejamento.md](2025_2_planejamento.md) — Semestre de execução de projetos reais com clientes (cronograma de entregas, definição tecnológica, avaliação).
- [questionario_impacto_2025_2.md](questionario_impacto_2025_2.md) — Instrumento de avaliação do impacto pedagógico e técnico da UCE (anônimo).

## Como estes materiais foram usados
O semestre `2025_1` precedeu o `2025_2`. O primeiro preparou os
estudantes tecnicamente (fundamentos, ambiente local e controle de versão).
O segundo colocou os estudantes em contato direto com clientes reais e
foi focado em entregas, comunicação e qualidade de software.

Recomendações de uso (na oferta original):
- A carga horária e as atividades foram adaptadas à realidade local e à disponibilidade dos parceiros quando necessário.
- Foram mantidos repositórios separados por equipe e promovidas práticas de revisão de código via GitHub (pull requests, issues).
- O `questionario_impacto_2025_2.md` foi utilizado para coletar evidências de aprendizagem e melhorar iterações futuras.

Resumo do conteúdo dos semestres:
- `2025_1`: conceitos e práticas introdutórias — HTML, CSS, PHP, configuração de ambiente com XAMPP, Git/GitHub, noções básicas de banco de dados e um projeto integrador (aplicação de envio de e-mails).
- `2025_2`: execução de projetos reais — levantamento de requisitos, definição tecnológica, design (Figma), desenvolvimento e entregas parciais e finais; critérios de avaliação e calendário de atividades.

Tecnologias destacadas em `2025_2` (exemplos de stacks usados pelas equipes):
- Equipe A: PHP (Laravel), HTML, CSS, PostgreSQL, Figma.
- Equipe B: React, Node.js (Express), PostgreSQL, Tailwind CSS, Figma.
- Equipe C: React, Ruby on Rails, PostgreSQL, Tailwind CSS, Figma, Jira.
## Uso de IA generativa
- As equipes utilizaram ferramentas de IA generativa como apoio para geração de textos, sugestões de código, criação de dados de teste e apoio à prototipação.
- Recomenda-se documentar quando a IA foi utilizada e submeter todos os resultados a revisão humana, preservando dados sensíveis.
